# Algorithm Challenge #36 – Count Each Word in a String (Level 3)

🧮 Problem Description  
-
This program reads a full line of text from the user and calculates the total number of words in the string.

The algorithm uses a delimiter-based strategy, where a space character defines word boundaries.

---

💡 What You’ll Learn
-
- Counting logical units (words) inside a string
- Using `find()`, `substr()`, and `erase()` for string traversal
- Differentiating between processing data and analyzing it
- Handling edge cases like multiple spaces
- Strengthening algorithmic accuracy and state control
